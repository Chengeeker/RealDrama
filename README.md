Flutter 多端独立短剧 / 影视应用，基于 guoapp 源码定制。站源请求、解析、下载和播放均在设备上完成，不依赖自建服务。当前源码开发快照和最近构建的 Android ARM64 APK 均为 **0.7.0+115**。设备验收状态见文末平台表。

最近构建的 Android ARM64 APK：[RealDrama-0.7.0+115-arm64-v8a.apk](安装包/RealDrama-0.7.0+115-arm64-v8a.apk)。包名 `com.real.drama`、versionName `0.7.0`、versionCode `2115`，32,402,674 字节，SHA-256 `FF93C6E95A8F13A4AA678AC1A136C9DDCA2BE6BA6FBEE18366007D7922ECF7A6`；仅含 `arm64-v8a` 原生库，17 个原生库的 60 个 ELF `PT_LOAD` 段均至少 16 KB 对齐，ZIP 对齐和 V2 签名通过，签名证书 SHA-256 `3EB0F6708904F8EF916C6A2572E394BA981EE25D64861344CF1921CA7EA17975`。未安装到设备验收。

发现页首次进入时只读取本地已缓存的剧库，不会在列表显示后再自动请求网络并替换当前内容。首次没有缓存时，可手动点击右上角“更新剧库”；下拉刷新仍只在已加载内容中换批。

首页自动跳过详情不可用、无分集或首集最终无法播放的短剧，并按本地用户暂存 12 小时；新发现的不可播内容会即时加入会话屏蔽集，避免刷新时被缓存重新插回首屏。刷新先用缓存内容启动播放，同时轮换获取网络目录；失败批次会让位给其他批次，空结果自动探测最多 8 个批次，加载中也可取消并重启。首页最近 30 部曝光内容按本地用户单独保存，跨底栏切换、清空最近观看和应用重启后仍保留；同 ID 或同名的近期剧目不自动重新推荐。切换到底栏其他页面不会销毁首页信息流：后台暂停当前播放器并保存进度，返回后保留原队列、播放页和未看完的位置继续播放；若启动页不是首页，则首次进入首页时才创建信息流并开始加载。若已启用目录没有新内容，首页提示用户到“猜你喜欢”单独清理去重记录后再重新推荐，不会静默把刚刷过的内容塞回来。首页以当前页为中心维护五部短剧窗口：最近两部已播放内容保留暂停的播放器会话，后两部预取详情、分集、播放地址和首段媒体数据；当前剧及后面五部的队列位置固定，返回时下一部不会变化；已播放的剧目也不参与重排；每部最多预取 4 MB，优先准备紧接当前的一部。预取计划切页后直接交给播放器，避免重复解析；预取数据不创建额外解码器，最多保留三个原生播放器实例。离开当前页时保存真实进度；返回保留窗口内的剧目接着原播放器会话播放，超出窗口后由本地观看记录恢复剧集和进度。视频显示在固定的 M3“推荐”顶栏与底部导航之间；普通模式直接使用 `contain` 完整显示源画幅，不裁切画面，必要时留黑边；清屏模式从同一原始视频画面按全屏视口 `cover` 铺满，不继承普通模式的裁切变换。进度线距视频区域底边 12dp。顶栏提供选集、红果弹幕、刷新和清屏；清屏会隐藏顶部栏、底部导航和系统栏，让视频扩展至全屏；点击视频恢复操作界面。普通刷流时视频不再叠加黑色渐变，标题和控件用文字阴影及自身底色保持可读；清屏与普通状态的视频亮度一致。普通播放时系统状态栏保持显示，图标亮度跟随主题。点击剧名/集数信息行时在手指按下阶段触发轻震动，再进入详情页；页面继续使用横向平移转场。

首页第一次开始播放前统一显示黑底加载指示器；候选封面、详情读取和播放地址准备期间不露出逐剧切换的封面或播放器加载层。不可播候选在加载层下跳过，首个可播放视频开始播放后才显示信息流；如果没有可播放内容，则转为现有空状态和重试入口。

刷流页与详情播放器使用不同的点按语义：刷流页轻点播放/暂停、双击喜欢；详情播放器轻点显示或隐藏控制栏，双击左右区域快退/快进 10 秒、中央区域播放/暂停。详情播放器仍保留选集、画质、倍速、进度条及普通播放器的集间切换；长按加速默认 2 倍速。横屏控制区按常见播放器的底部控制带布局：倍速、画质、选集等操作在上，进度与时间在最下方，整体贴近底部安全区。弹幕开关位于底部控制栏原设备推送位置，设备播放推送入口已移除。暂停与弹幕控件沿用当前 M3 / Material You Monet 配色。首页画质单独配置目标清晰度，并按源站提供的媒体流解析；没有该档时回退到可用档位。首页播放/暂停切换，以及长按加速生效时提供轻震动，并遵守个性化中的全局震动开关。

站源管理的一键更新限为最新目录、一页历史和三部资料补齐；也可逐页加载或选择“加载后续所有页”。分页状态只在接口提供总页数时显示总量，缺少可靠总数时会标为未知，加载结束后显示本次可确认的页数。批量续载由单个站源串行低频执行，同一时刻只允许一个批量任务，单次最多 1000 页或 30 分钟；超时、限流、错误或手动停止会保留已加载内容，403/429 遵循站点退避时间且不会自动重试。红果 App 2xx 空响应或格式异常会进行有限重试。源站真实下架或返回 HTTP 404 的内容会从首页暂存跳过；客户端不能修复上游不存在的页面、权限限制或持续故障。

首页偏好将红果的数百个原始标签按“猜你喜欢”的 5 个大类和 25 个二级题材分组；大类与二级题材均可批量开关，具体原始分类按需打开查看。发现页红果分类栏使用相同的两级入口：默认选中“全部”时只显示一级分类行，点选大类后再显示该大类的二级题材；具体目录入口沿用服务端分类，其余题材在已分页目录结果中本地筛选。目录切换使用预建分类索引和会话内存候选，避免每次点击都全量扫描并同步写入本地用户数据。红果服务端实际仍只有真人剧、漫剧、AI剧三个目录入口，不会为数百标签逐项发请求。

发现页移除“内容形式”一级分类；“全部”和“推荐”统一显示“全部内容形式、真人剧、漫剧、AI剧”二级入口。切换剧目题材时先显示加载状态；分类索引仅在剧目标签变化时重建，大批量筛选分段让出 UI 线程。

首页偏好“全选”超过 300 个分类时原先被校验拒绝、却误报存储空间不足；每站源的分类上限统一为 4096。播放设置顺序为站源管理、首页偏好、猜你喜欢、最近观看。首页播放器把详情放到剧名/集数信息行，选集放到底栏上方，进度线贴近导航栏上沿；弹幕按钮移出右侧操作栏，播放/暂停中心提示在点击后约一秒淡出。

首页偏好目录批次按轮转游标开始读取。首页最近 30 部曝光剧目按本地用户保存在设备上，跨底栏切换、清空最近观看和应用重启沿用；新候选在排序前优先排除同 ID 或规范化同名内容。目录只剩近期已刷内容时会提示单独清理去重记录，不会自动回退显示；用户也可以在“猜你喜欢”单独重置去重记录，而不动最近观看、播放进度或收藏。每次新启动仍采用不同的目录起始批次。首页“猜你喜欢”根据观看深度、连续观看分集、短划/停留、喜欢、不喜欢和追剧记录估算题材偏好，并把长线信号与当前会话信号融合；会话反馈最多保留 60 条并按本地用户隔离，应用进程结束后清除。推荐反馈只重排当前剧及后面五部稳定队列之外、最多 60 部未播放候选；当前队列和已播放剧目的位置固定，新目录批次按最新信号排序。“不喜欢”同时本地过滤该剧，并在当前会话中给相关题材负向信号；“追剧”沿用本地收藏，同时作为长期兴趣正向信号。默认兴趣排序权重为长期兴趣 38%、本次兴趣 27%、热度或播放量 10%、新鲜度 10%、题材探索 10%、随机扰动 5%；热度与播放量共用一个信号，缺少热度值时才回退到播放量。全随机是用户主动选择的选项，会在当前已请求且通过首页白名单、不喜欢和去重过滤的候选中随机排列，不使用热度、兴趣或题材多样性评分。候选集合仍受站源返回的目录页限制，不代表从所有站源全量目录均匀抽取。权重按本地用户持久化并进入配置备份。首版是透明的设备端规则排序，不上传行为、不使用视频 Embedding 或机器学习模型。

站源首次使用默认仅显示红果，其余已编译站源在「设置 → 播放设置 → 站源管理 → 显示的站源」中关闭；用户可逐项开启。已有隐藏列表会原样保留；旧版尚无隐藏列表但记录了其他当前可用站源时，会保留红果和上次选中的站源，确保重启后仍回到上次站源。发现页不提供“全部站源”，只在已显示的站源中切换，并按用户保存上次选择。隐藏源不参与目录、分类、站源管理状态轮询或首页推荐请求；隐藏时会取消该源仍在运行的站源管理任务。隐藏设置按用户保存，并进入配置备份。启动页默认是发现；可在「设置 → 个性化 → 启动界面」改为首页、追剧或设置。

本轮沿用应用图标 `icon12.png`。手机底栏统一为 48dp 高的 M3 扁平导航，只显示文字、不显示图标；选中项用次级容器色轻量高亮。个性化页不再提供导航布局切换。

“关于应用”弹窗使用圆角矩形图标，并将应用名、版本和说明按层级排版。

站源管理的源卡片使用浅色圆角描边；网络与资源选择菜单采用紧凑宽度，停止任务后收起诊断展开区。

底栏「首页」使用沉浸式刷剧流：只从「设置 → 播放设置 → 首页偏好」开启的站源与分类请求内容；未开启的来源和类别不进入首页请求或结果。剧目同时命中多个分类时，命中任一明确关闭分类就会过滤，不能靠另一个开启标签绕过；红果细分类只在已开启的真人剧、漫剧或 AI 剧根类内生效。站源默认关闭，首次开启时自动全选已读取的分类；每源卡片可折叠，分类收在限高可滚动窗口中，并支持全选、反选和逐项调整。用户主动反选到空后会保持为空，不回退到全站内容。成人向站源/类别默认关闭，按普通站源开关操作；直播不进入短剧信息流。红果偏好顺序读取三个顶层剧种的本地目录缓存和初始目录批次元数据，补充发现页使用的细分类；已启用来源进入偏好页时自动加载分类。全屏自动播放，上下滑换剧、点剧名/集数信息行进详情；轻点暂停/继续、双击点赞、首页长按临时 2 倍速，选集、追剧和不感兴趣均可在播放页操作。详情重试会强制刷新请求并显示源站错误。首页详情请求失败或返回空剧集的条目会自动跳过并按本地用户缓存 12 小时；连续跳过 20 部后暂停自动取页，可手动刷新继续。宽屏下视频居中保持竖屏观感，视频显示范围位于“推荐”顶栏与不透明底部导航之间，进度线位于选集与导航之间。选集数字在窄格内单行缩放显示，不再把两位数拆行。已选择内容内部再按本地观看行为排序。

此白名单只控制首页推荐，不是全应用年龄门禁；发现页和站源管理仍允许手动浏览当前可见站源。对未成年人做全局限制还需要家长验证与跨页面的成人内容阻止策略。

## 使用

| 功能 | 操作 |
| --- | --- |
| 首页刷剧 | 仅请求首页偏好中开启的站源和分类；剧目命中任何关闭分类时，即使也命中开启分类仍会过滤。红果细分类仅在已开启的真人剧、漫剧或 AI 剧根类中生效。红果偏好依次读取三个顶层剧种的本地目录缓存和初始目录批次元数据，显示发现页使用的细分类。无选择时提示先设置，不回退到其他来源。竖屏自动播放；上下滑切换短剧，点击剧名/集数信息行进入剧目资料，详情页使用横向平移转场；底部选集入口可切换分集。不感兴趣会按本地用户隐藏该剧。刷新优先继续已选分类的目录分页并跳过最近已刷内容；没有新候选时提示单独清理去重记录，不自动重复推荐 |
| 浏览 | 标题栏依次提供排序与筛选、榜单、多选下载和展开搜索。分类保持独立一行，内容区左右滑动切类；支持默认、名称、自然季号、上线日期、热度、播放量排序及连载状态筛选。下拉刷新只在当前已加载结果中换一批，不请求站源；右上角「更新剧库」用于显式网络更新。列表下滑接近底部自动加载下一页，底部「加载更多」为兜底 |
| 搜索 | 红果合并官网与名称索引，并补查同名季数；剧果、帝果、青空支持在线分页搜索；韩小圈和 91短剧当前只返回一批站点搜索结果；鬼片匹配 RSS 最新条目；直播按用户名搜索；黄果三个入口仅筛选已加载目录。最近 20 次搜索按用户保存 |
| 推荐 | 仅红果分类栏在「全部」后显示「推荐」，可切换真人剧、漫剧、AI 剧并分别记住位置 |

| 卡片与批量下载 | 卡片「更多」提供收藏、状态和下载选集；电脑右键，电视菜单键。发现页长按卡片或点标题栏「多选下载」，一次最多 50 部 |

### 网络与资源设置

管理员从「设置 → 网络与资源」选择自动、直连或手动代理，手动地址支持 HTTP、HTTPS、SOCKS5 / SOCKS5h。代理地址默认遮蔽、不进入备份；设备内播放服务始终绕过代理。自动模式读取系统静态代理与排除列表，恢复前台及每 30 秒更新；代理不会关闭 TLS 校验。

同页的「网络诊断」复用站源健康检查，可选择一个可见站源，检查目录、分集、播放地址、密钥与媒体连接，并显示步骤耗时、主机和 HTTP 状态。媒体连接最多读取一个媒体片段前 1 KB，不保存完整视频。连接诊断不是 CDN 全速测试，也不证明后续每个播放地址都可用。按站源分类保存现位于「下载设置 → 保存方式」，只影响新任务，已有文件路径不变。个性化设置可选择下次启动进入首页、发现、追剧或设置；默认值为发现，该选择纳入配置备份。

目录请求并发可设 1–6、间隔 0–5000 毫秒（默认 3 / 250ms）；下载并发默认 2、可设 1–6。仍保留前台优先、后台让行、取消、退避及请求数量边界。

### 局域网互联：追剧同步与推送播放（已接入，待验证）

两台设备在同一局域网直连，自动同步追剧记录或接续播放，不依赖账号服务器。服务类型 `_zgj-link._tcp`（DNS-SD / mDNS），按设备 ID 合并多网卡地址，首次配对记录证书指纹，后续连接固定校验。

入口：「追剧 → 标题栏同步」。设置页不再单列“设备互联”入口；手动同步默认「双向合并」，可选覆盖对方 / 覆盖本机，先「查看预览」再执行；自动同步仅发送改动条目与删除标记，播放期间约每 10 秒发送进度。冲突记录保留候选，用户从同步页逐项处理。

## 开发与构建

Flutter `3.47.4`、Dart `3.12+`、Go `1.24.1+`、Python `3.10+`。Android 需要 JDK 17、SDK 36、NDK `28.2.13676358`；Windows 需要 Visual Studio C++ 桌面组件及 MinGW-w64 x64；iOS 需要 macOS、完整 Xcode 和 CocoaPods。

构建脚本对子进程默认设置 `GOPROXY=https://goproxy.cn,direct`、`GOSUMDB=off`，同名环境变量可覆盖。

~~~sh
python3 scripts/build_android.py                 # 红果单源，arm64-v8a
python3 scripts/build_android.py --all-sources   # 全站源，arm64-v8a
python3 scripts/build_android.py --cn-mirrors    # 国内镜像
~~~

~~~powershell
.\scripts\build_windows.ps1
.\scripts\build_windows.ps1 -AllSources
.\scripts\build_windows.ps1 -ChinaMirrors
~~~

~~~sh
python3 scripts/build_ios.py
python3 scripts/build_ios.py --all-sources
python3 scripts/build_ios.py --core-only [--simulator]
python3 scripts/build_ios.py --export-options /path/to/ExportOptions.plist
~~~

产物在 `dist/android`、`dist/windows`、`dist/ios`，红果版以 `hongguojian-` 开头，全站源版以 `zhenguojian-` 开头。

首次 Android 调试先编译对应架构核心，再运行：

~~~sh
python3 scripts/build_native.py --platform android --abi arm64-v8a
flutter pub get --enforce-lockfile
flutter run
~~~

调试全站源版：先给 `build_native.py` 加 `--all-sources`，再 `flutter run --dart-define=ALL_SOURCES=true`；iOS 对应 `build_ios.py --core-only --all-sources`。完整 Android Release 包统一使用 `scripts/build_android.py`，它会同步设置 Dart 常量和 Go 编译参数；不要单独编译 Flutter 后复用不同站源变体的原生库，应用启动时会校验二者是否一致。

各平台在线播放统一使用 `media_kit` / libmpv，包括 Android 普通 HLS/MP4 与带专用 CENC 解密密钥的计划；播放地址仍由设备端站源适配和本机流代理提供，现有五部预加载、请求头、分集、倍速、弹幕、进度保存与错误恢复沿用。Android 的 `video_player` / Media3 播放适配已从当前源码移除。合并和导出继续使用 [FFmpegKit min-gpl](https://github.com/sk3llo/ffmpeg_kit_flutter)（含 GPL 媒体组件），不参与普通在线播放。
